# Letopis for Homebrew

Install [Letopis](https://github.com/zdkadiev/letopis), source-linked project memory for AI coding agents:

```sh
brew install zdkadiev/tap/letopis
```

Native packages are provided for macOS and Linux on Apple Silicon/ARM64 and Intel/x86_64. No Rust toolchain or model provider is required to install and use full-text search.

Upgrade with:

```sh
brew update
brew upgrade letopis
```

See the [Letopis README](https://github.com/zdkadiev/letopis#quick-start) for the knowledge format and JSON interface.
